# Full Screen Gesture

Edge-swipe navigation for Android, so the phone can run without on-screen navigation buttons.

- Swipe in from the **left or right edge** → Back
- Swipe **up from the bottom** → Home
- Swipe up from the bottom and **pause** → Recents

Uses an Accessibility Service with thin invisible edge strips. It does not read the screen.
Edge width, bottom height, per-edge toggles and vibration are adjustable in the app.

Every build carries a version tag `1.1.0-b<run number>` in the APK file name and on the app's main screen.
